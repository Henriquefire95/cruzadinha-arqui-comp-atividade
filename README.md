# Sonic Zone: Cruzadinha de Arquitetura Computacional

Jogo de palavras cruzadas temático inspirado no universo Sonic para fixação dos conceitos de Arquitetura Computacional.

## Como Jogar
1. Leia as pistas divididas entre **Horizontais** e **Verticais**.
2. Clique nas casas numeradas do tabuleiro e digite as letras correspondentes (sem acentos e sem espaços).
3. Clique no botão **Conferir** para validar suas respostas. As palavras corretas ficam verdes e as incorretas ficam vermelhas.
4. Acompanhe seu progresso no contador de acertos no topo da tela.
5. Caso queira tentar novamente, clique em **Reiniciar** para limpar todo o tabuleiro.

## Palavras e Pistas Utilizadas

### Horizontais
1. **MICROCONTROLADOR**: Chip completo com processador, memória e periféricos integrados para sistemas embarcados.
5. **CACHE**: Memória intermediária veloz entre o processador e a memória principal.
6. **DATABUS**: Via bidirecional que transporta informações entre processador, memória e periféricos.
8. **FLASH**: Armazenamento não volátil regravável eletricamente em blocos, usado em pendrives.
10. **RAM**: Memória principal volátil de leitura e escrita que perde dados sem energia.
12. **DUALCORE**: Processador que possui dois núcleos físicos independentes no mesmo chip.
13. **QUADCORE**: Processador equipado com quatro núcleos físicos para processamento paralelo.

### Verticais
2. **ROM**: Memória não volátil que guarda instruções permanentes de inicialização.
3. **REGISTRADORES**: Memória interna ultrarrápida da CPU usada para guardar dados temporários.
4. **ADDRESSBUS**: Via unidirecional por onde o processador envia locais físicos de memória.
7. **ULA**: Parte da CPU que faz as contas e as operações lógicas.
9. **CPU**: Cérebro do computador responsável por buscar, decodificar e executar instruções.
11. **DMA**: Recurso que permite periféricos acessarem a memória sem passar pelo processador.
