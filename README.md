# Cruzadinha de Arquitetura Computacional

Jogo de palavras cruzadas sobre Arquitetura Computacional, feito com HTML, CSS e JavaScript puros (sem bibliotecas), para a Atividade Avaliativa III.

**Jogo online:** COLE-AQUI-O-LINK-DO-GITHUB-PAGES

## Como jogar

1. Leia as pistas das listas **Horizontais** e **Verticais**.
2. Encontre o número da pista no tabuleiro e digite a resposta, uma letra por casa.
3. Clique em **Conferir**: palavras certas ficam verdes, erradas ficam vermelhas e o contador mostra quantas você acertou.
4. Clique em **Reiniciar** para limpar tudo e jogar de novo.

## Termos do jogo (16)

CPU, ULA, UC, registradores, cache, RAM, ROM, EEPROM, Flash, memória de massa, DMA, address bus, data bus, microcontrolador, dual core e quad core.

## Estrutura

- `index.html`: estrutura da página
- `style.css`: tema visual de placa de circuito
- `script.js`: dados das palavras, geração do tabuleiro, conferência e reinício
